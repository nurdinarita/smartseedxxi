# Smart Seed XXI

## Cara Install

1. Clone repository

```bash
git clone https://github.com/nurdinarita/smartseedxxi.git
```

2. Masuk ke folder project

```bash
cd smartseedxxi
```

3. Install dependency

```bash
npm install
```

4. Jalankan aplikasi

```bash
npm start
```

## Akses Aplikasi

Secara default aplikasi berjalan pada:

- http://localhost:3000/
